# 编辑、删除与重新生成说明

本版本完成第二条数据管理功能链：

```text
生成 DeepSeek 笔记
→ 编辑标题、摘要、知识点和问题
→ 保存修改
→ 记录服务商、模型和耗时
→ 重新生成前确认费用
→ 删除笔记
→ 12 秒内撤销删除
```

## 编辑笔记

进入笔记详情页，点击“编辑”。可以修改：

- 课程名称
- 标题
- 摘要
- 知识点
- 待复习问题
- 待核对内容

知识点、问题和待核对内容按“一行一条”保存。空行会被自动删除。

保存后返回详情页，页面和首页列表会读取最新数据。

## 重新生成

成功笔记的详情页会显示“重新生成”。点击后先弹出费用提示，因为每次重新调用 DeepSeek 都会产生 Token 消耗。

确认后：

1. 状态切换为“整理中”。
2. 旧内容暂时保留在页面上。
3. 新结果成功后整体替换旧内容。
4. 新结果失败时保留旧内容，显示错误并允许再次重试。

## 删除和撤销

点击详情页“删除”后，会显示确认弹窗。

确认删除后：

1. 笔记立即从首页移除。
2. 关联图片暂时保留。
3. 首页底部出现“撤销”按钮。
4. 12 秒内点击撤销，笔记和原图都会恢复。
5. 超过 12 秒，关联图片会被删除。

删除过程不删除其他笔记的图片。

## 模型记录

DeepSeek 生成成功后，详情页会记录：

```text
DeepSeek · deepseek-flash · 生成耗时
```

现有旧笔记没有这些字段时，详情页不会显示模型信息，数据仍可正常读取。

## 手工验收

1. 使用相册选择一张测试板书，等待 DeepSeek 生成成功。
2. 点击“编辑”，修改标题和一条知识点，保存。
3. 返回首页，确认标题已更新。
4. 再次进入详情，确认模型和生成耗时仍然存在。
5. 点击“重新生成”，检查费用确认弹窗。
6. 取消一次，旧内容不能改变。
7. 再次确认生成，观察“整理中”和最终结果。
8. 点击“删除”，确认弹窗。
9. 删除后点击“撤销”，确认笔记恢复。
10. 再删除一条笔记，等待超过 12 秒，确认撤销栏消失。
