# 课本章节与相关笔记说明

本版本完成“课本章节绑定”和“再次看见旧知识”的第一版：

```text
编辑笔记
→ 填写教材、章节和页码
→ 保存绑定关系
→ 在详情页查找相关旧笔记
→ 按关键词重合度、教材章节和课程排序
→ 打开历史笔记
```

## 绑定课本

打开笔记详情，点击“编辑”，填写：

- 教材名称
- 章节
- 页码

例如：

```text
教材名称：数据结构教材
章节：第3章 树与二叉树
页码：42
```

绑定信息会显示在详情页的模型信息下方。AI 对话整理出的新笔记会继承原笔记的课本位置。

## 查找相关旧笔记

点击详情页“查找相关旧笔记”。

当前版本使用本地匹配，不调用 AI，也不上传内容。匹配依据包括：

1. AI 生成的关键词。
2. 课程名称相同。
3. 教材名称和章节相同。
4. 旧笔记标题或知识点中的关键词。

排序规则：

- 每个匹配关键词加分。
- 同一教材章节额外加分。
- 同一课程作为辅助加分。
- 不显示当前笔记自身。
- 只显示已经整理成功的笔记。

## 为什么先用关键词

关键词匹配结果可解释，不需要额外服务器费用，适合第一版验证。

后续可以升级为：

- 中文分词。
- 语义向量检索。
- 图片相似度匹配。
- AI 二次排序。

当前不承诺自动后台扫描。用户必须主动点击“查找相关旧笔记”，避免持续读取教材或摄像头。

## 手工验收

1. 准备至少两条包含相同知识点的笔记。
2. 分别编辑两条笔记，填写相同的教材和章节。
3. 打开其中一条，点击“查找相关旧笔记”。
4. 应出现另一条笔记，并显示匹配关键词或“同一教材章节”。
5. 点击结果，应进入对应笔记详情。
6. 如果当前笔记没有相关记录，应显示空状态说明。
