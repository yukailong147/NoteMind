# 全局搜索与相关提示说明

本版本增加两个学习库功能：

```text
首页搜索全部笔记
→ 在本地匹配标题、摘要、知识点、问题、关键词、课程、教材和章节
→ 按匹配程度排序
→ 点击打开笔记详情

打开笔记详情
→ 自动计算相关旧笔记数量
→ 按钮显示“查找相关旧笔记 · 数量”
```

## 搜索范围

搜索只包含已经整理成功的笔记，不显示草稿、处理中和失败的记录。

字段权重从高到低为：

1. 标题
2. 关键词
3. 知识点
4. 待复习问题
5. 教材章节
6. 课程、教材名称和摘要

因此标题直接包含查询词的笔记，会排在只在摘要中出现该词的笔记前面。

## 本地搜索

搜索直接读取手机中的 `notes.json`，不上传关键词，也不调用 DeepSeek。

空查询不执行搜索，页面显示输入提示。没有匹配结果时显示空状态。

## 相关旧笔记数量

笔记详情页使用与“查找相关旧笔记”相同的匹配规则，提前计算数量。

例如：

```text
查找相关旧笔记 · 3
```

点击后进入相关笔记列表。列表中的匹配关键词、章节和打开详情行为保持不变。

## 自动化测试

搜索引擎有以下单元测试：

- 中文标题匹配。
- 标题不含查询词时通过关键词匹配。
- 教材章节匹配。
- 空白查询返回空结果。
- 只搜索成功笔记。
- 标题匹配排在摘要匹配前面。

## 手工验收

1. 在首页点击“搜索笔记”。
2. 输入已有笔记标题中的关键词。
3. 检查结果数量和排序。
4. 输入一个不存在的词，检查空结果提示。
5. 清空输入，检查起始提示。
6. 打开一个含相关笔记的详情页，检查按钮上的数量。
7. 点击相关旧笔记入口，检查列表数量是否一致。
