# ClassroomNotes

当前版本的 Android 实现：

```text
输入课程
→ 调用系统相机、从相册选择或生成测试板书
→ 保存待整理草稿
→ 使用模拟或真实 AI 生成笔记
→ 保存图片和 notes.json
→ 显示待整理、整理中、成功或失败
→ 失败后保留草稿并允许重试
→ 编辑标题、摘要、知识点和问题
→ 删除并在 12 秒内撤销
→ 成功笔记可以重新生成
→ 保存服务商、模型和生成耗时
→ 围绕当前笔记进行多轮 AI 对话
→ 将对话整理成一条新笔记
→ 绑定教材名称、章节和页码
→ 根据关键词和章节查找相关旧笔记
→ 重启后重新读取
```

## 当前阶段

- 使用 Kotlin 和 Android 传统 View 界面。
- 支持系统相机拍照、系统图片选择器和开发测试图片。
- 没有 AI 配置时使用模拟生成器，不要求联网。
- 配置接口地址、模型和密钥后自动使用真实 AI。
- 拍完照先保存草稿，再进入整理状态。
- 网络失败时保留原图、草稿和错误信息。
- 可以手工修正 AI 识别结果。
- 删除笔记后 12 秒内可以撤销。
- 重新生成前会提示可能产生费用。
- AI 对话和失败重试记录保存在手机本地。
- 对话可以整理成独立的新笔记，不覆盖原始笔记。
- 笔记可以绑定教材位置，并从详情页查找历史相关内容。
- 图片保存在应用私有目录 `files/photos`。
- 笔记保存在应用私有目录 `files/notes.json`。
- 重启应用后可以再次读取。

## 运行方法

1. 用 Android Studio 打开本目录。
2. 等待 Gradle Sync 完成。
3. 启动模拟器 `Medium_Phone_API_37.0`。
4. 点击运行按钮。
5. 点击“测试：生成示例板书”可以在没有相机的情况下验证保存流程。
6. 点击“从相册选择板书”可以导入手机或模拟器中已有的图片。

## 目录说明

- `MainActivity.kt`：首页、拍照、示例图片和笔记列表。
- `NoteDetailActivity.kt`：笔记详情和图片显示。
- `NoteItem.kt`：一条笔记的数据结构。
- `NoteStore.kt`：把笔记保存为 JSON，并在启动时读回。
- `activity_main.xml`：首页布局。
- `activity_note_detail.xml`：详情页布局。
- `item_note.xml`：列表中的单条笔记卡片。

## 相册图片

相册选择使用 Android 系统照片选择器，只把用户主动选中的图片复制到应用私有目录，不申请读取全部相册的权限。该功能在真实手机和模拟器上都可使用。
